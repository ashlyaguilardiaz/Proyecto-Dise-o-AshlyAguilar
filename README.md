# El secreto del Árbol de Cristal

## Descripción
Esta es una página web en forma de cuento. La historia pasa en el Bosque Encantado de Montree, donde viven Lumina y Aelion. Los dos tienen que juntar tres elementos mágicos para salvar el Árbol de Cristal. La hice en la materia de Programación Web y usé Git y GitHub para guardar los cambios del proyecto.

## Características principales
- Tiene varias secciones: inicio, personajes, historia, viaje, lugares, elementos, la parte interactiva, final y créditos.
- Tiene un menú arriba para ir a cada sección.
- Los colores y las letras son moradas y suaves, y los botones cambian cuando pasás el cursor.
- Tiene una pregunta donde se elige una respuesta y la página dice si está bien.
- Tiene imágenes de los personajes y de los lugares.
- Se ve bien también en pantallas pequeñas.

## Tecnologías
HTML, CSS, JavaScript, Git y GitHub.
